# Founder skill (11 skills)

Origem: https://github.com/Jakeschincariol/founder-skill (licença MIT, Jake Schincariol).

Testam um negócio antes de lançar: conselho (board), concorrentes, painel de 100 compradores simulados, preço, oferta, CFO, marketing, marca, operação, lançamento e plano de negócio.

## No app do Claude (claude.ai / Cowork)

Cada skill é um ZIP separado. Em **Configurações → Capacidades → Skills → Enviar skill**, envie os ZIPs que quiser desta pasta. Ordem recomendada de uso:

board → competitors → consumer → pricing → offer → cfo → marketing → brand → ops → launch → plan

## No Claude Code

Já estão instaladas no projeto em `.claude/skills/founder-*`. Use `/founder-board`, `/founder-cfo` etc. Os arquivos gerados ficam na pasta `founder/`. As ferramentas em Python precisam de Python 3.8+ (nada para instalar).
